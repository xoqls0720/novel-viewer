작품 폴더 연결
한 번 연결하면 켤 때마다 저절로 불러와요. 파일은 원래 자리에 두고, 열 때 그 화만 읽어요. 드라이브에서 받은 화는 기기에 남겨서 다음엔 인터넷 없이도 열려요.
'노벨'·'만화'·'웹툰'이 들어 있는 폴더(예: 문서/novel)를 고르면 종류별로 알아서 나눠 연결해요.
'노벨'·'만화'·'웹툰'처럼 종류별 폴더를 하나씩 연결하면 종류가 맞게 나뉘어요.

그림 바로 만들기 · 프로그램에서 노벨AI로

그림을 앱 안에서 바로 뽑는 건 윈도우 프로그램에서만 돼요(브라우저는 노벨AI가 막아 둬요). 아이패드·폰에서는 아래 '노벨AI에서 만들기'로 프롬프트를 복사해 쓰고, 만든 그림은 컴퓨터에서 동기화돼요.
노벨AI 사이트 → 톱니(User Settings) → Account → Get Persistent API Token 을 눌러 나온 긴 글자를 넣으세요. 비밀번호가 아니에요.
장
'설정 가져오기'를 누르면 노벨AI 창이 열려요. 거기서 평소처럼 그림을 한 장 만들면 토큰·모델·크기·스텝·샘플러를 그대로 가져와서, 다음부터는 같은 설정으로 그려요. 만든 그림은 장면 노트에 저장되고 동기화돼요.

그림으로 이어 가기

노벨AI는 다른 사이트에서 바로 그림을 요청할 수 없어요. '노벨AI에서 만들기'를 누르면 프롬프트가 복사되고 노벨AI가 열려요. 만든 그림을 가져오면 장면 노트로 보관되고, 거기서 프로크리에이트로 보내 고쳐 그릴 수 있어요.

기기끼리 맞추기

구글 드라이브추천
구글 계정으로 한 번만 시작하면 진도·형광펜·메모·장면 노트·집필실 원고가 드라이브의 앱 전용 숨은 칸에 맞춰져요. 그다음부터는 켤 때, 앱으로 돌아올 때, 고칠 때 저절로 맞춰요.
고급

등록할 주소(승인된 JavaScript 원본):
OneDrive
마이크로소프트 계정으로 한 번 로그인하면 진도·형광펜·메모·장면 노트·집필실 원고가 OneDrive의 앱 전용 폴더(앱/Novelist)에 맞춰져요. 작품 폴더도 OneDrive에서 바로 연결해 아이패드에서 열 때 그 화만 받아요.

  1. portal.azure.com → 앱 등록 → 새 등록. 이름 Novelist, 지원 계정은 개인 Microsoft 계정만.
  2. 인증 → 플랫폼 추가 → 단일 페이지 애플리케이션:
  3. 같은 곳에서 모바일 및 데스크톱 애플리케이션 추가: http://localhost (윈도우 프로그램용)
  4. API 권한 → Microsoft Graph 위임: Files.Read, Files.ReadWrite.AppFolder, offline_access
  5. 개요의 애플리케이션(클라이언트) ID를 아래에 넣어요. 비밀번호는 필요 없어요.
같은 와이파이로 보여 주기아이패드·폰
처음부터 켜져 있어요. 같은 와이파이의 폰·아이패드에서 아래 QR 을 찍거나 주소를 열면 이 컴퓨터의 서재를 바로 봐요(영상·번역 포함). 폴더 연결도 로그인도 필요 없어요. 이 컴퓨터가 켜져 있는 동안만 보여요. 진도·형광펜은 그 기기 안에만 남아요.
어디서나 열기 (Cloudflare 터널)
켜면 와이파이·데이터·WARP 와 상관없이 폰에서 열려요. 폰에는 아무것도 설치하지 않아도 돼요. 대신 서재와 다운로더가 인터넷에 열리고, 주소 속 긴 열쇠만이 남을 막아요(https 로 암호화). 주소는 남에게 보내지 마세요. 주소는 PC 를 다시 켜면 바뀌어요: 폰에서는 웹 버전 Novelist 를 홈 화면에 두고 PC 서재 열기를 누르면 늘 지금 주소로 가요(구글 드라이브 맞추기를 켜 둔 경우).
PC로 맞추기메모·AI 키
이 PC와, PC 주소(같은 와이파이·Tailscale·어디서나 열기)로 연 폰·아이패드가 메모·형광펜·진도·집필실 원고·장면 노트·설정·AI 키를 저절로 맞춰요. 고치면 몇 초 안에, 그 밖에는 30초마다 맞춰요. 로그인이 필요 없고 PC 밖으로 나가지 않아요.

이 기기에 저장

굿노트 · 프로크리에이트 연동
그림 화면의 보내기 → 굿노트·프로크리에이트를 고르면, 그림을 복사하고 그 앱을 바로 띄워요. 앱이 열리면 붙여 넣기만 하면 돼요(굿노트: 쪽을 길게 눌러 붙여넣기 / 프로크리에이트: 캔버스에서 세 손가락 아래로 쓸기 → 붙여넣기). 앱이 안 열리면 자동으로 공유 시트로 바꿔 보내요. PSD 레이어와 PDF는 '공유 시트'로 바꾸면 보낼 수 있어요.
다시 가져올 때: 굿노트는 PDF 또는 이미지로 내보내기, 프로크리에이트는 공유 → PNG 또는 PSD로 파일 앱에 저장한 뒤, 메모 탭의 그림 가져오기를 누르고 그 파일을 고르면 돼요.

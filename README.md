# 노벨 뷰어

소설·웹툰·만화 뷰어와 작가용 분석·글쓰기 도구입니다. 이 저장소에는 프로그램만 있고 작품 파일은 들어 있지 않습니다. 작품은 각 기기에서 '폴더 열기'로 넣으면 그 기기 안에만 저장됩니다.

- 주소: https://xoqls0720.github.io/novel-viewer/
- 컴퓨터: 크롬·엣지에서 위 주소를 열고 주소창 오른쪽 설치 아이콘을 누르면 앱으로 설치됩니다.
- 아이폰: 사파리에서 열고 공유 → '홈 화면에 추가'.
- Ollama(무료, 컴퓨터만): ollama.com에서 설치 → `ollama pull gemma3:12b` → `Ollama_켜기.bat` 실행 → 설정 탭 '연결 확인'.

자세한 설명은 비공개 저장소 novel의 viewer/README.md에 있습니다.

고치는 법은 [DEVELOPING.md](DEVELOPING.md)를 보세요.

# 노벨 뷰어

소설·웹툰·만화 뷰어와 작가용 분석·글쓰기 도구입니다. 이 저장소에는 프로그램만 있고 작품 파일은 들어 있지 않습니다. 작품은 각 기기에서 '폴더 열기'로 넣으면 그 기기 안에만 저장됩니다.

- 주소: https://xoqls0720.github.io/novel-viewer/
- 컴퓨터(윈도우 프로그램): `NovelViewer-Setup-버전.exe`를 실행해 설치합니다. 서명이 없는 프로그램이라 처음에 "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누릅니다. 바탕화면과 시작 메뉴에 '노벨 뷰어'가 생깁니다.
- 컴퓨터(브라우저 앱): 크롬·엣지에서 위 주소를 열고 주소창 오른쪽 설치 아이콘을 누르면 앱으로 설치됩니다.
- 윈도우 프로그램에서 구글 드라이브 동기화를 쓰려면, 구글 클라우드의 같은 OAuth 클라이언트에 **승인된 리디렉션 URI** `http://127.0.0.1:53682/` 를 추가하고, 설정 탭에 클라이언트 ID와 **클라이언트 보안 비밀번호**를 넣은 뒤 '연결'을 누릅니다. 로그인은 기본 브라우저에서 해요.
- 아이폰: 사파리에서 열고 공유 → '홈 화면에 추가'.
- Ollama(무료, 컴퓨터만): ollama.com에서 설치 → `ollama pull gemma3:12b` → `Ollama_켜기.bat` 실행 → 설정 탭 '연결 확인'.

자세한 설명은 비공개 저장소 novel의 viewer/README.md에 있습니다.

고치는 법은 [DEVELOPING.md](DEVELOPING.md)를 보세요.
